## 🧩 Self-Initiated Contribution to LingoQuest

I independently contributed to the LingoQuest open-source project by adding:

- 🤖 **ChatBot Integration**: Enabled users to interact with the platform in multiple languages, enhancing engagement and accessibility.
- 🎬 **Video Sidebar Component**: Created a responsive video sidebar to showcase learning materials with thumbnails and navigation.

These features were added to improve the user experience and learning flow on the platform.

### 🛠️ Tech Stack Used

- **Next.js** – App framework for server-side rendering and routing
- **React.js** – Component-based frontend development
- **PostgreSQL** – Relational database for structured data storage
- **DrizzleORM** – Type-safe ORM for database operations
- **NeonDB** – Serverless PostgreSQL for scalable and efficient cloud DB
- **ShadCN UI** – Accessible and customizable component library for clean UI
- **TailwindCSS** – Utility-first CSS framework for responsive design
- **Axios** – HTTP client for chatbot API integration

**Note:** The frontend of this project is in frontend branch of this repository. You can access my frontend contribution part of video sidebar and chatbot integration from that branch of repository.
